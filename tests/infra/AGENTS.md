# Test fixture lessons

- A copied PNG literal had a bad IDAT checksum and would have made the upload test fail for the wrong reason. Generate binary image fixtures from chunks and verify their CRCs before using them in browser acceptance.
- MediaWiki Siteinfo does not publish a `dbname` field. Check the current API contract before asserting undocumented response fields; verify declared database isolation through unique C1 identities and cross-wiki behavioral probes.
- An API 200 through a container gateway does not prove browser pages can follow MediaWiki's canonical-host redirects. Run a page-flow probe; for containerized browser tests, set the disposable runtime's canonical URL to its reachable gateway before relying on navigation or cookies.
- VisualEditor can show a first-run welcome dialog asynchronously, then leave `.mw-page-container` inert briefly after the dialog closes. Always wait for and dismiss the dialog, wait until that class-based page container is no longer inert, then target the pinned editor root `.ve-ce-rootNode[role="textbox"][contenteditable="true"]`.
- On macOS, `/tmp` resolves to `/private/tmp`; validate temporary cleanup against the resolved parent and unique prefix rather than comparing the unnormalized `/tmp` string.
- Runtime `setup` may regenerate managed settings on rerun. Reapply disposable browser-only config overrides after every setup, then restart that project before browser navigation.
- Check the target worktree's actual public entrypoint before cross-worktree integration probes; sibling worktrees may expose `runtime.py` without the `scripts/wiki` dispatcher.
- Match browser controls to the pinned application's current accessible DOM. A stale VisualEditor class selector can miss a working editor; verify the visible toolbar, accessible textbox, save flow, and persisted article outcome.
- Check case-sensitive extension class names against the pinned source: DiscussionTools 1.46 uses `.ext-discussiontools-ui-replyWidget` with a capital `W`, not the older guessed lowercase selector.
- Before saving a browser-edited page, wait for the full marker in VisualEditor's linear document data as well as the visible editor, then assert Save is enabled. Rapid input can update the DOM before the model catches up; click inside the first article paragraph, use the editor's end-of-document shortcut, append with paced keyboard input, and include annotated-character text values when checking linear data.
- DiscussionTools reply text can appear in its composer before the VisualEditor model has the complete marker. Wait for the full marker in `ve.init.target` linear document data before submit, then wait for the reply widget to close before checking the article and reloading.
- DiscussionTools reply links are server-rendered before their click handlers bind. Wait for `html.ext-discussiontools-init-ready` (set after controller initialization) before clicking Reply.
- Vector may render duplicate watch/unwatch anchors; use a scoped accessible control instead of a strict broad selector.
- Linux Docker cannot route `host.docker.internal:host-gateway` to a service bound only on host loopback. Run the browser container with host networking and use `127.0.0.1`; retain Docker Desktop's host alias on macOS.
- PHP `array_count_values()` converts numeric-string keys to integers. Cast keys back to strings before regex/string operations, and include numeric-token fixtures in attribution checks.
- Use pinned toolchains for test gates instead of assuming host binaries are healthy; this Mac's Homebrew Node aborted on a missing `simdjson` dylib, so do not install or repair host packages for the check.
- Set a container's interpreter either as its entrypoint or as an explicit command, not both; mount the repository at `/repo` when test scripts derive paths from their repository-relative location.
- For whitespace-sensitive edit fixtures, record explicit UTF-16 ranges and verify them by slicing the listed revisions. A generic character diff can choose a different equivalent whitespace boundary than the producer's token alignment.
- Per-revision byte/token limits do not bound transitive attribution ancestry. Charge a global lineage-reference budget before copying ancestors into replacement tokens or events, and fail closed when it is exhausted.
- Unique shared words can move across edit gaps or be restored after a reorder. Detect order inversions and test move/revert sequences so events and spans remain marked ambiguous.
- Compact spans must keep the full union of inherited ancestry and every member token ID; partial-selection consumers should include only IDs whose token ranges overlap the selection.
- MediaWiki JobFactory passes `(Title, params)` to ordinary mapped Job subclasses. Match the factory signature and exercise a real queued run; lint/direct construction alone will not catch this mismatch.
