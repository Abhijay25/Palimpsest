# Wikipedia-style editor workspace

User-requested reference: Wikipedia's Vector article interface. White canvas (#ffffff), dark text (#202122), blue links and actions (#3366cc), secondary text (#54595d), gray rules (#a2a9b1), and light gray utility panels (#f8f9fa). Serif article titles at 29px; Arial body and controls, 16px body / 13–14px metadata.

Desktop shell: wordmark, working topic search, left contents navigation, central article, right functional text-size and width preferences. Article tabs expose real destinations. Source metadata resembles Wikipedia utility tables, and paired excerpts use a restrained diff-table layout. Mobile removes sidebars and stacks comparison columns. Visible keyboard focus, skip link, semantic landmarks and responsive controls remain required.

Independent prototype identity is explicit in the header/footer. No Wikipedia logo or implied affiliation. Source links, uncertainty and snapshot dates remain visible. Reading preferences persist locally. Comparison behavior and native MariaDB vector scoring are unchanged.

Article-first flow: the root opens the Tornedalians mock article, while search remains at /articles. Each real snapshot article has a Compare languages tab, a language selector, anchored contents and a source metadata infobox. A yellow maintenance-style notice demonstrates discrepancies using explicitly illustrative text and links to the real tracker. The notice dismisses for the current page view. No fabricated imagery or unmarked factual summaries.

Evidence review states: muted red #972d26 / #fff0ed for possible conflicts, blue #24539c / #eef4ff for extra coverage, purple #64429a / #f5f0fc for framing, green #246547 / #edf7f0 for equivalent information. State names accompany every color. Use exact original-language excerpts with highlighted relevant words, English demo translations and stable source revision links. Explanations distinguish missing selected evidence from absence across the whole article. Mock outputs are labeled at section and translation level; original excerpts remain real. Review controls save locally and never publish.

Current reader flow: choose two or three language editions before inspecting results. Pair selection filters cached findings; triplets combine pairwise findings. Default view shows only possible conflicts. Other categories have neutral gray surfaces and no source highlights. Classification uses template criteria and exact selected source sentences. Separate local machine translations support Finnish/Swedish evidence; originals stay visible.

Source-first revision: searchable language pills replace visible checkboxes. Section labels provide context without an accordion; original evidence and highlights are visible immediately. Only review criteria and editing tools are collapsible. Headings prioritize selected date/number differences rather than unrelated bill numbers or generic AI titles. Highlighting is conditional and represents an apparent discrepancy for human review, not verified contradiction.

Update watchlist: amber status means a linked passage changed and needs review. A relationship title and baseline note precede a side-by-side exact diff and current counterpart. Removed text uses red with strikethrough; additions use green with an explicit legend. Gray translation panels label local machine output and possible errors. Review outcomes and notes are visible; optional Decisions checks stay secondary. Mobile stacks evidence columns and retains the Link passages action. Sandbox edits, imported revisions and demo baselines have explicit provenance. Reviews here persist in MariaDB, while existing comparison controls retain their browser-local behavior.

Tornedalians showcase: Article / Compare languages / Update tracker share navigation. Snapshot comparisons remain pinned to August 2025. Historical replay uses actual edits ending at those snapshots, event-time counterpart retrieval and persistent reviews. Sandbox examples stay outside the showcase.

Evidence convention: current article edition always on the left, other edition(s) on the right; mobile preserves that DOM order vertically. Comparison evidence is partitioned by current lang; missing current-edition evidence gets an honest placeholder rather than substituting another language. Triplets stack other editions in the right column. Cross-language update details place the target/current passage left and the changed foreign diff right. Local issue details remain a single current-article diff. Preserve lang in comparison forms and navigation.

Winter War Semantic timeline: Read/Operate surface using the existing Wikipedia shell, four language lanes on one UTC date axis and a keyboard-accessible chronological evidence list. Color and shape describe change categories, never a language's reliability: red diamond factual change, purple triangle framing, blue square information, neutral circle unresolved/wording. Dense markers display edit counts and narrow the list. Edition/category/date controls filter cached events. The chosen edition is the first lane; historical comparison keeps ours left and changed foreign text right. Exact deletions/additions and source revision links precede secondary score details. Mobile uses a smaller SVG coordinate system to preserve label size, then stacks evidence. No gamified bias scores or inferred editor intent.
