About the data

Semantic questions, not repeated passages

Each row groups a provisional underlying question. Source passages are matched symmetrically across the selected editions using multilingual embeddings and MariaDB nearest neighbours, then assessed by the Decisions API.

Three observed difference types

Possible contradiction: incompatible assertions about the same subject and scope.

Different framing: a materially different emphasis, evaluation or attribution.

Additional context: meaningful detail in one selected passage, not proof that it is absent from the entire other article.

Sampling and uncertainty

Cells represent actual stored assessments within the selected calendar period. Dashed gaps were not assessed. Missing question findings do not establish agreement or resolution. Exact source revisions remain authoritative; translations are machine output and may contain errors.

Detector observations

All detector classifications retain their original identity. Detector buckets use the assessed source revision’s edit date; scan time is shown separately. Checks run only on demand. Empty, failed, partial and unassessed checks remain distinct. No continuous historical coverage is implied.

Preview review markers

Confirm and false-positive flags are stored in this browser, scoped to the selected run, question and source occurrence. They do not publish edits.
