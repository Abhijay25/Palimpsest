About the data

Local multilingual E5-small embeddings (384 dimensions) represent paragraph chunks: target 280 tokens, cap 400. MariaDB retrieves the three nearest passages per other language within the same topic, with adjacent context. This is exact cosine retrieval, not clustering or a truth score.

Decisions classifies the retrieved evidence and checks flagged differences. Equivalent information is hidden. Translation runs locally using Argos/CTranslate2. Historical replay stores real revisions and persistent reviewer notes in MariaDB; counterparts come from versions available at the time of each edit.

The article and comparison use the supplied dataset revisions. Historical edits are replayed, not live monitoring.
