## Determinism

`PALIMPSEST_RESULT_CACHE_DIR` enables persistent complete-response caching for `audit-diff` and `audit-page`; `X-Palimpsest-Fresh: 1` bypasses and refreshes it.
`python -I eval/determinism.py <edits.jsonl> --out <dir> --repeats 3` measures fresh-run flag-set stability without letting the cache hide variance.

- Judge: `stage2_v10` on gemini-4-hydrogen LOW, temperature 0, seed 7 (`GEMINI_SEED`). v10 = v8 + per-span `span_type`; `docs/flag-policy.md` applied in code (INTENSIFIER/REGISTER suppressed, SIZE_RANK_CLAIM → fact check).
- Evidence: Exa highlights (new + old sentence queries) with lexical fallback; context routing (`PALIMPSEST_CONTEXT_MODE=rule`): ABSENCE claims search the whole cited document.
- Value check: cited-source highlights + Wikidata (`palimpsest/value_check.py`); old VALUE_CHANGED review rule off (`PALIMPSEST_VALUE_SWAP_REVIEW=1`).
- Out of sync (`palimpsest/consistency.py`): changed value still stated elsewhere on the page → admin flag with quote, section and jump link; semantic pass → review. Real data: 5/25 Finnish swaps, 0/25 controls.
- Reviewer (gemini-4-argon): only on value changes. B2 cherry-pick: off (`PALIMPSEST_CHERRY_PICK=1`; 0/12 real catches).
- Citation rot: every new/changed cited URL live-checked (cap 25, 4 s each, 6 s total), grouped by domain; twice-timed-out sites → review "did not respond"; Wayback drift only with `PALIMPSEST_A1_DRIFT=1`.
- Citation dates: future / mismatched rendered dates (19/20 real cases).
- Stealth: hidden text (comments, CSS, zero-width; full CSS colour names; hidden = contrast < 1.5:1), cited-page render scan (escalates only on strong instructions).
- UI (`infra/wiki/extensions/PalimpsestFlags`): floating summary bar, multi-select filter dropdown, rail cards (grow upward at the bottom), markup-tolerant anchoring, Carbon UI review applied.
