# Blame design and decisions

Base: prompt commit15f713a; infrastructure PR1 remains open, head e49be05, main17b73fc. Feature lives in isolated worktree/branch feature/blame-implementation because feature/blame-sdd is occupied by the parent checkout. Parent checkout, runtime and bulk caches are read-only references.

1. Native PHP extension/APIModule and ResourceLoader browser module; no core fork or core schema retrofit. Own derived cache/checkpoint schema only if needed. Existing development mount loads extension. Use installed1.46.2 APIs and primary documentation, not recalled older namespaces.
2. Attribution compares ordered original local wikitext revisions. Compare bounded Myers/LCS versus unique-anchor/patience approaches on explicit fixtures before choosing. Unchanged aligned tokens retain last-change attribution; a changed word belongs to that changing revision. Reintroduced wording has a new last-change, with earlier introduction/lineage only where demonstrable. Duplicate/moved/reverted text must carry ambiguity, not fabricated unique origins. Store replacement/deletion events with stable ancestry/neighbor anchors so removed wording can be inspected from a surviving selection. Plain edit-time is not snapshot-validity time.
3. Render the selected snapshot through pinned Parsoid internally with source-range/pagebundle metadata. Public REST HTML was observed to omit data-parsoid. Verify each mapped visible text against its exact source byte range and convert all exposed offsets to UTF-16. Exclude transclusions/extensions/generated content and unsupported syntax. No first-substring matching. Preserve links/headings/citations; show unmapped coverage explicitly. Backend owns safe rendered HTML and annotated offsets; browser never invents source alignment.
4. Imported provenance is a trusted operator-generated read-only per-wiki bundle in its existing /etc/palimpsest config mount (exporter --install), checked against source batch inventories and C4 maps before export. At request time match actual local revision text/hash/time/identity and parent mappings. Import prefix is not a locally authenticated Wikipedia identity. Missing/stale/mismatched imported metadata invalidates attribution; local-only pages and subsequent local edits have explicit local provenance. Do not expose suppressed text/user/comment through cache or stale bundles.
5. UTC dates: asof<=bound, before<bound, ranges inclusive. Date-only asof/end uses23:59:59Z; strict-before date/start uses00:00:00Z. Same-second ties sort local revision ID descending. Only documented English patterns/manual ISO controls; show interpreted bounds before apply. Do not fall back later. A source cutoff does not certify live Wikipedia state after that date.
6. Bound revision count, input bytes, token-diff work, response bytes and concurrent jobs. Small sample may compute synchronously. Larger work uses explicit POST/CSRF build and durable bounded checkpoint/resume with pending/failed/expired states. Cache keys include wiki/page/revision/algorithm/schema and visibility/metadata fingerprint; recheck read rights and suppression before every response. Do not return partial results as complete.
7. SVT deferred: database system-time during import is unrelated to source edit time; indexed source revision metadata and immutable derived results suffice. No benchmark supports adding system-versioned tables now.
8. Inherit Vector2022 typography/color/layout, quiet revision accents and inline disclosure. Do not redesign the wiki. Existing precise product brief replaces optional preference questions per direct human instruction. Skill review must respect the explicit one-Sol-reviewer/three-Luna cap; no extra hidden reviewer.
